# Промпт для авторки сайту: частина 2 «Перевір себе»

Скопіюй усе, що нижче риски, і передай авторці сайту (або її ШІ-помічнику). До промпту додай файли `perevir-sebe.js` і `demo.html`.

---

Ти допомагаєш вбудувати блок «Перевір себе» у сайт «Калькулятор PISA: Україна» (статична сторінка на GitHub Pages, без бекенду). Не вигадуй цифр, фактів і додаткових функцій. Усе, що позначено «ПЕРЕВІРИТИ» або «TODO», не вигадуй, а залиш команді.

## Що робить блок

1. Сайт відкривається не з форми калькулятора, а з трьох завдань базового рівня PISA (рівень 2): читання, математика, природничі науки, по одному.
2. Над завданнями і в підсумку є речення: «Це демонстрація, а не вимірювання твого рівня: три завдання не можуть показати, якого рівня PISA досягає людина.»
3. Людина обирає відповідь (A–D). Після цього:
   - кнопки блокуються, правильна відповідь підсвічується зеленим, хибний вибір червоним;
   - з'являється пояснення (2–3 речення);
   - з'являється речення: «Це завдання базового рівня (рівень 2). Цього рівня {з предмета} не досягають {X}% українських 15-річних.»
4. Після третього завдання з'являється підсумок:
   - «Правильних відповідей: N з 3»;
   - якщо 3 з 3: «Тобі це було легко. А майже половина однолітків не досягає цього рівня з читання і математики:», інакше: «Ці завдання — базового рівня. А майже половина однолітків не досягає цього рівня з читання і математики:»;
   - список: читання — 45,4% українських 15-річних; математика — 46,0%; природничі науки — 34,8% (приблизно третина);
   - кнопка «Перейти до калькулятора» ховає блок і показує форму калькулятора (частина 1).
5. Після того як калькулятор показав результат, під ним з'являється речення, що повертає до тесту:
   «Пам'ятаєш завдання {з предмета} на початку? Рівня такого завдання досягають {pct}% {твоя група} і {pct_інша}% {інша група}.»
   - {pct} — поле `pct_level2` з `data/pisa_ukraine_calculator.csv` для обраної комбінації «предмет × стать × достаток»;
   - «інша група» — протилежна стать із тим самим рівнем достатку (ПЕРЕВІРИТИ: це рішення має затвердити команда);
   - якщо `enough_data` не true, замість відсотка пишеться «замало даних».
   - Приклад з реальних даних: «Пам'ятаєш завдання з математики на початку? Рівня такого завдання досягають 40,8% дівчат з родин нижчого достатку і 46,1% хлопців з родин нижчого достатку.»

## Цифри (тільки ці)

Частка українських 15-річних, які не досягають рівня 2 (PISA 2025, 17 з 27 регіонів, 7105 учнів):

| Предмет | Не досягають рівня 2 |
|---|---|
| Читання | 45,4% |
| Математика | 46,0% |
| Природничі науки | 34,8% (ПЕРЕВІРИТИ: межу рівня 2 з природничих наук 2025 року ще треба звірити з технічним звітом PISA 2025) |

Цифри для речення-повернення беруться з `data/pisa_ukraine_calculator.csv` (частина 1), у код їх не вписувати.

## Умови використання (обов'язково)

- Завдання PISA ОЕСР поширює за ліцензією CC BY-NC-SA 3.0 IGO. Тобто: некомерційне використання, із зазначенням ОЕСР як джерела, а сайт із цими завданнями треба поширювати на тих самих умовах.
- Переклад має містити застереження, що це не офіційний переклад ОЕСР. На сайті вже є рядок: «Завдання: © OECD, PISA. Ліцензія CC BY-NC-SA 3.0 IGO. Переклад не є офіційним перекладом ОЕСР; у разі розбіжностей чинним є оригінал.» (ПЕРЕВІРИТИ точне формулювання застереження на сторінці умов ОЕСР.)
- PDF-файли ОЕСР на сайт не викладати (так прямо сказано в умовах), лише посилання на них.

## Чого не писати

- Не писати «не змогли б розв'язати це завдання» чи «це завдання розв'язують X%». Дані показують частку учнів, які досягають або не досягають рівня 2, а не частку тих, хто розв'язав саме це завдання. Тому формулювання: «не досягають рівня цього завдання», «рівня такого завдання досягають».
- Не робити висновків про рівень людини за трьома відповідями.
- Цифра описує групу учнів, а не прогноз для конкретної людини.

## Як підключити

```html
<section id="perevir-sebe"></section>
<section id="calc" hidden> ...калькулятор... <div id="perevir-link"></div></section>
<script src="perevir-sebe.js"></script>
<script>
  PerevirSebe.start({ mount: "#perevir-sebe", onDone: () => {
    document.getElementById("perevir-sebe").hidden = true;
    document.getElementById("calc").hidden = false;
  }});
  // після того як калькулятор показав результат:
  // PerevirSebe.showLink({ mount: "#perevir-link", rows, subject, gender, escs });
  // rows = PerevirSebe.parseCsv(текст файлу data/pisa_ukraine_calculator.csv)
</script>
```

Робочий приклад — `demo.html`. Відкривати через сервер (GitHub Pages або `python -m http.server`), бо з диска `fetch` CSV не працює.
