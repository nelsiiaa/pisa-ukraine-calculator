# Кнопки «Поділитися» для калькулятора PISA: Україна

Дві кнопки, які працюють без сервера (підходить для GitHub Pages):

1. **Скопіювати посилання.** Копіює адресу виду `https://ваш-сайт/?subject=math&sex=boy&income=high`. Хто відкриє її, одразу побачить той самий результат.
2. **Зберегти картинку.** Створює вертикальну картинку 1080×1920 (формат сторіс) з ознаками, великою цифрою, діапазоном, шкалою порівняння, текстом «Що це означає» та адресою сайту. На телефоні відкривається меню «Поділитися» (Telegram, Instagram тощо). Якщо меню немає, картинка завантажується як файл `pisa-result.png`.

## Файли

- `share.js` — увесь код кнопок. Це єдиний файл, який потрібен справжньому сайту.
- `index.html` — тестова сторінка з вигаданими цифрами. Показує, як підключати `share.js`. На справжній сайт не потрапляє.

## Як підключити до справжнього сайту (3 кроки)

**Крок 1.** Покладіть `share.js` поруч зі сторінкою калькулятора й підключіть перед кодом калькулятора:

```html
<script src="share.js"></script>
```

**Крок 2.** Додайте в блок результату дві кнопки й порожній рядок для повідомлень:

```html
<button id="btn-link" type="button">Скопіювати посилання</button>
<button id="btn-image" type="button">Зберегти картинку</button>
<div id="share-status" role="status"></div>
```

**Крок 3.** Після коду калькулятора викличте `PisaShare.init` і передайте дві функції:

```js
PisaShare.init({
  linkButton: "#btn-link",
  imageButton: "#btn-image",
  statusEl: "#share-status",

  // Повернути те, що зараз показано на екрані (або null, якщо результату ще немає)
  getResult: function () {
    return {
      subject: "math",        // reading | math | science
      sex: "boy",             // girl | boy
      income: "high",         // low | mid | high
      percent: 67,            // велика цифра
      low: 63, high: 71,      // діапазон (можна не передавати)
      ukraine: 52,            // усі учні України
      oecd: 65,               // ОЕСР (якщо цифри немає, поставте null: рядок зникне)
      meaning: "Текст із блоку «Що це означає», такий самий, як на сайті."
    };
  },

  // Викликається, якщо сторінку відкрили за чужим посиланням.
  // Тут треба вибрати ці значення у формі й показати результат.
  onLoadFromLink: function (state) {
    // state = { subject: "math", sex: "boy", income: "high" }
  }
});
```

## Що треба узгодити з командою

- **Назви варіантів.** У `share.js` зверху є список `ALLOWED`: які значення бувають (`reading`, `girl`, `mid` тощо) і як вони підписані на картинці. Якщо у формі калькулятора інші значення або підписи, змініть їх у цьому списку.
- **Текст «Що це означає».** Береться з `getResult().meaning`. Якщо він дуже довгий, на картинці його буде скорочено трикрапкою.
- **Адреса на картинці.** Береться автоматично з адреси сторінки. Якщо потрібен інший підпис, додайте в `PisaShare.init` рядок `siteLabel: "назва.github.io/pisa"`.

## Перевірено

Тестувалося в браузері Chromium (комп'ютерна версія). Перевірено: копіювання посилання; відкриття посилання (форма й результат відновлюються); ігнорування зіпсованих або підроблених посилань; створення PNG 1080×1920; передача картинки в меню «Поділитися» (імітація телефона); завантаження файлу, якщо меню немає або не спрацювало; дуже довгий текст і відсутність цифри ОЕСР.

**Не перевірено на справжніх телефонах** (iPhone/Android з Telegram та Instagram). Це треба зробити вручну після публікації на GitHub Pages.

## Як перевірити вручну

Відкрийте `index.html` через будь-який локальний сервер (наприклад, у VS Code розширення Live Server) або після публікації на GitHub Pages. Натисніть «Показати», потім кожну з двох кнопок.
