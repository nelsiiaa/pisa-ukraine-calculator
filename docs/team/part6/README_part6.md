# Поділитися результатом: калькулятор PISA: Україна

Частина №6 проєкту. Дві кнопки, які працюють без сервера (підходить для GitHub Pages):

1. **Скопіювати посилання.** Копіює текст «Чи залежить освіта від того, хто ти? Є калькулятор на даних PISA 2025, який показує це в цифрах. Ось подивись на мої результати, а які вийдуть у тебе?» і з нового рядка
   посилання виду `https://nelsiiaa.github.io/pisa-ukraine-calculator/?subject=math&gender=female&escs=mid`.
   Хто відкриє посилання, одразу побачить той самий результат.
2. **Поділитись посиланням та картинкою результатів.** Створює картку 1080×1320 (пропорція 1:1,2: Telegram показує її в чаті без обрізання, підходить і для Instagram): вибрані ознаки,
   головна цифра з 95% діапазоном, порівняння «твоя група / усі учні України / середнє ОЕСР»,
   блок «Що це означає» і застереження «це середнє для групи, а не прогноз для людини». Адреси сайту на картці немає.
   На телефоні відкривається меню «Поділитися», і в чат іде **одне повідомлення**: текст, картинка й активне
   посилання (текст із посиланням іде як підпис до картинки). Якщо меню немає (наприклад, на комп'ютері),
   файл `pisa-result.png` завантажується, а текст із посиланням копіюється, щоб вставити їх разом.

## Файли

- `share.js` — увесь код кнопок. Це єдиний файл, який потрібен справжньому сайту.
- `index.html` — тестова сторінка з вигаданими цифрами. На справжній сайт не потрапляє.

## Для авторки сайту: як підключити (3 кроки)

**Крок 1.** Покладіть `share.js` у репозиторій поруч зі сторінкою калькулятора й підключіть перед кодом калькулятора:

```html
<script src="share.js"></script>
```

**Крок 2.** У блок результату додайте дві кнопки й рядок для коротких повідомлень:

```html
<button id="btn-link" type="button">Скопіювати посилання</button>
<button id="btn-image" type="button">Поділитись посиланням та картинкою результатів</button>
<div id="share-status" role="status"></div>
```

**Крок 3.** Після коду калькулятора викличте `PisaShare.init`:

```js
PisaShare.init({
  linkButton: "#btn-link",
  imageButton: "#btn-image",
  statusEl: "#share-status",
  decimals: 0,            // скільки знаків після коми на картці; має збігатися з тим, що показує сайт
  extraParams: ["track"], // необов'язково: додаткові параметри посилання, які теж треба прочитати

  // Повернути те, що ЗАРАЗ показано на екрані (або null, якщо результату ще немає)
  getResult: function () {
    return {
      subject: "math",     // read | math | scie   (стовпець subject у таблиці)
      gender: "female",    // female | male        (стовпець gender)
      escs: "mid",         // low | mid | high     (стовпець escs)
      percent: 54.0,       // pct_level2
      low: 51.5,           // ci_low
      high: 56.5,          // ci_high
      enoughData: true,    // enough_data; якщо false, ділитися цифрою не дозволяємо
      meaning: "Текст із блоку «Що це означає», такий самий, як на сайті.",
      // Необов'язково: додаткові ознаки сайту (наприклад, клас). extraChips показуються на картці,
      // extra додається в посилання (?track=general)
      extraChips: ["10–11 клас (загальна освіта)"],
      extra: { track: "general" },
      // ukraine та oecd передавати не обов'язково: якщо їх немає, береться з брифу
      // (Україна: 54,6 / 54,0 / 65,2; ОЕСР: 69,0 / 65,1 / 74,3 для читання / математики / природничих наук)
    };
  },

  // Викликається, якщо сторінку відкрили за чужим посиланням.
  // Тут треба вибрати ці значення у формі й показати результат.
  onLoadFromLink: function (state, extra) {
    // state = { subject: "math", gender: "female", escs: "mid" }
    // extra = { track: "general" } (лише якщо вказано extraParams і параметр є в посиланні)
  }
});
```

## Що узгодити з командою

1. **Посилання й «Перевір себе».** Зараз сайт спершу пропонує три завдання. Пропоную, щоб людина, яка відкрила чуже посилання, одразу бачила калькулятор із результатом (завдання можна пройти потім). Якщо команда вирішить інакше, це змінюється в `onLoadFromLink`.
2. **Скільки знаків після коми** показує калькулятор (у брифі цифри з одним знаком: 54,6%). Картка має показувати те саме, інакше цифри на сайті й на картинці розійдуться.
3. **Природничі науки.** У брифі межа базового рівня для природничих наук позначена «перевірити». Поки це не підтверджено, картка для цього предмета спирається на непідтверджену цифру.
4. **Текст «Що це означає»** береться з `meaning`. Якщо він дуже довгий, на картці його буде скорочено трикрапкою (до 7 рядків).
5. **Текст до посилання** можна змінити в `init`: `shareText: "..."`. Якщо при копіюванні потрібне лише посилання без тексту, додайте `copyWithText: false`.
6. **Попередній перегляд посилання.** Картка з заголовком і малюнком, яку Telegram показує під «голим» посиланням, береться з тегів сторінки сайту (`og:title`, `og:description`, `og:image` у `<head>`), а не з цього коду. Вона однакова для всіх, особистий результат у ній показати не можна. Якщо цих тегів на сайті немає, їх варто додати.

## Що перевірено

У браузері Chromium (комп'ютерна версія), 20 автоматичних перевірок: копіювання посилання; відновлення форми й результату за посиланням; ігнорування зіпсованих, підроблених і застарілих посилань; створення PNG 1080×1320; передача картинки в меню «Поділитися» (імітація телефона); запасне завантаження, якщо меню немає або дало помилку; блокування, якщо `enoughData: false`; дуже довгий текст; відсутність цифр ОЕСР та України в `getResult`; довгий текст «Що це означає» (шрифт зменшується, а якщо не вміщається, прибираються цілі речення); додаткові параметри посилання.

**Не перевірено:** підключення до справжнього сайту (його форма й кнопки скриптом не видно ззовні) і справжні телефони з Telegram та Instagram. Це треба зробити вручну після підключення. Telegram зазвичай залишає текст підписом до картинки. Instagram у меню «Поділитися» текст і посилання часто не приймає, тож для сторіс посилання можливо доведеться додати вручну.
