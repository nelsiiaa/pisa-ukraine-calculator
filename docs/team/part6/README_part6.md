# Поділитися результатом: калькулятор PISA: Україна

Частина №6 проєкту. Дві кнопки, які працюють без сервера (підходить для GitHub Pages):

1. **Скопіювати посилання.** Копіює адресу виду
   `https://nelsiiaa.github.io/pisa-ukraine-calculator/?subject=math&gender=female&escs=mid`.
   Хто відкриє її, одразу побачить той самий результат.
2. **Зберегти картинку.** Створює вертикальну картку 1080×1920 (формат сторіс): вибрані ознаки,
   головна цифра з 95% діапазоном, порівняння «твоя група / усі учні України / середнє ОЕСР»,
   блок «Що це означає», застереження «це середнє для групи, а не прогноз для людини» і адреса сайту.
   На телефоні відкривається меню «Поділитися» (Telegram, Instagram). Якщо меню немає, файл
   `pisa-result.png` завантажується.

## Файли

- `share.js` — увесь код кнопок. Це єдиний файл, який потрібен справжньому сайту.
- `index.html` — тестова сторінка з вигаданими цифрами. На справжній сайт не потрапляє.

## Для авторки сайту: як підключити (3 кроки)

**Крок 1.** Покладіть `share.js` у репозиторій поруч зі сторінкою калькулятора й підключіть перед кодом калькулятора:

```html
<script src="share.js"></script>
```

**Крок 2.** У блок результату додайте дві кнопки й рядок для коротких повідомлень:

```html
<button id="btn-link" type="button">Скопіювати посилання</button>
<button id="btn-image" type="button">Зберегти картинку</button>
<div id="share-status" role="status"></div>
```

**Крок 3.** Після коду калькулятора викличте `PisaShare.init`:

```js
PisaShare.init({
  linkButton: "#btn-link",
  imageButton: "#btn-image",
  statusEl: "#share-status",
  decimals: 0,            // скільки знаків після коми на картці; має збігатися з тим, що показує сайт

  // Повернути те, що ЗАРАЗ показано на екрані (або null, якщо результату ще немає)
  getResult: function () {
    return {
      subject: "math",     // read | math | scie   (стовпець subject у таблиці)
      gender: "female",    // female | male        (стовпець gender)
      escs: "mid",         // low | mid | high     (стовпець escs)
      percent: 54.0,       // pct_level2
      low: 51.5,           // ci_low
      high: 56.5,          // ci_high
      enoughData: true,    // enough_data; якщо false, ділитися цифрою не дозволяємо
      meaning: "Текст із блоку «Що це означає», такий самий, як на сайті.",
      // ukraine та oecd передавати не обов'язково: якщо їх немає, береться з брифу
      // (Україна: 54,6 / 54,0 / 65,2; ОЕСР: 69,0 / 65,1 / 74,3 для читання / математики / природничих наук)
    };
  },

  // Викликається, якщо сторінку відкрили за чужим посиланням.
  // Тут треба вибрати ці значення у формі й показати результат.
  onLoadFromLink: function (state) {
    // state = { subject: "math", gender: "female", escs: "mid" }
  }
});
```

## Що узгодити з командою

1. **Посилання й «Перевір себе».** Зараз сайт спершу пропонує три завдання. Пропоную, щоб людина, яка відкрила чуже посилання, одразу бачила калькулятор із результатом (завдання можна пройти потім). Якщо команда вирішить інакше, це змінюється в `onLoadFromLink`.
2. **Скільки знаків після коми** показує калькулятор (у брифі цифри з одним знаком: 54,6%). Картка має показувати те саме, інакше цифри на сайті й на картинці розійдуться.
3. **Природничі науки.** У брифі межа базового рівня для природничих наук позначена «перевірити». Поки це не підтверджено, картка для цього предмета спирається на непідтверджену цифру.
4. **Текст «Що це означає»** береться з `meaning`. Якщо він дуже довгий, на картці його буде скорочено трикрапкою (до 7 рядків).
5. **Адреса на картці** береться з адреси сторінки автоматично. Інший підпис можна задати рядком `siteLabel: "..."` в `init`.

## Що перевірено

У браузері Chromium (комп'ютерна версія), 15 автоматичних перевірок: копіювання посилання; відновлення форми й результату за посиланням; ігнорування зіпсованих, підроблених і застарілих посилань; створення PNG 1080×1920; передача картинки в меню «Поділитися» (імітація телефона); запасне завантаження, якщо меню немає або дало помилку; блокування, якщо `enoughData: false`; дуже довгий текст; відсутність цифр ОЕСР та України в `getResult`.

**Не перевірено:** підключення до справжнього сайту (його форма й кнопки скриптом не видно ззовні) і справжні телефони з Telegram та Instagram. Це треба зробити вручну після підключення.
