# Специфікація: Калькулятор PISA: Україна

Зведені вимоги всіх частин в одному форматі. Джерела: завдання для команди та промпти учасниць (частини 2–5). Оригінальні файли частин 2 і 6 лежать у `docs/team/`.

**Продукт.** Статична сторінка на GitHub Pages. Людина проходить три завдання PISA базового рівня, обирає предмет, стать і соціально-економічне становище родини й бачить, яка частка українських 15-річних із такими ознаками досягає базового рівня (рівень 2 PISA), що це означає, наскільки великий розрив і що з цим робити.

**Дані.** `data/pisa_ukraine_calculator.json` (і `.csv`). Мікродані OECD PISA 2025, Україна (17 з 27 регіонів), 7 105 учнів. Пораховано з вагами учнів, 10 правдоподібними значеннями та 80 реплікаційними вагами BRR-Fay (`scripts/calculator_table.py`). Звірено з опублікованим: дівчата − хлопці в читанні 31,7 бала; базовий рівень з математики 54,0%.

**Тексти.** Усі в `js/texts.js` («тут редагують тексти»). Логіка не містить жодного тексту.

**Тести.** `node --test` — перевірки з промптів частин 2–5 (19 тестів).

**Загальні правила формулювань (для всіх частин).**
- Цифра описує групу, а не конкретну людину.
- Лише зв'язок, не причина: без «через це», «спричиняє», «завдяки», «призведе», «гарантує».
- Без термінів: ESCS, plausible values, довірчий інтервал, «рівень 2» (крім частини 2, де рівень названо прямо).
- Без стереотипів про стать і звинувачень.
- Усі числа лише з таблиці даних.

## Частина 1. Основний калькулятор

| | |
|---|---|
| **Що бачить користувач** | Форма: предмет, стать, становище родини. Велика цифра «39%», діапазон «35%–44%», шкала з трьома точками (твоя група, усі учні України, середнє ОЕСР), речення про різницю з Україною, кнопка «Спробувати іншу комбінацію». |
| **Правила** | Кнопка «Показати» неактивна, поки не обрано всі три пункти. `enough_data = false` → «замало даних» (правило: менше 30 учнів або 5 шкіл; зараз таких груп немає). Речення про різницю — за полем `vs_ukraine`. |
| **Код** | `app.js` (`renderMain`), тексти — `CALC` у `texts.js`. |
| **Перевірити** | Межу базового рівня з природничих наук (409,54, з циклів 2015–2022) — у технічному звіті PISA 2025. |

## Частина 2. «Перевір себе»

| | |
|---|---|
| **Що бачить користувач** | Перед калькулятором — три оприлюднені завдання ОЕСР рівня 2 (читання, математика, природничі науки). Після відповіді: правильна/хибна, пояснення, «Цього рівня … не досягають X% українських 15-річних». Підсумок N з 3 і перелік часток. Після результату калькулятора — речення-повернення: «Пам'ятаєш завдання … Рівня такого завдання досягають X% {група} і Y% {інша група}». |
| **Правила** | Це демонстрація, а не вимірювання (речення на сайті). Не писати «розв'язують X%» — лише «досягають рівня такого завдання». «Інша група» = протилежна стать, те саме становище. Частки беруться з таблиці даних, не вписуються в код. |
| **Код** | `js/quiz.js` (основа — `perevir-sebe.js` команди), завдання — `QUIZ.ITEMS` у `texts.js`. |
| **Завдання** | «The Play's the Thing» (PISA 2009, 474 бали, відповідь B); «Charts» Q5 (PISA 2012, 428 балів, B); «Acid Rain» Q3 (PISA 2006, 460 балів, A). |
| **Ліцензія** | CC BY-NC-SA 3.0 IGO; на сайті — рядок про ОЕСР і неофіційний переклад. PDF ОЕСР не викладати, лише посилання. |
| **Перевірити / TODO** | Додати уривок п'єси (рядки 1–29) у `stimulus_html` завдання з читання. Додати діаграму як `img/charts.png` (поки показується посилання на оригінал). Звірити переклади з оригіналом. Точне формулювання застереження на сторінці умов ОЕСР. |

## Частина 3. «Що це означає»

| | |
|---|---|
| **Що бачить користувач** | 2–3 речення: що таке базовий рівень з предмета; скільки досягає група порівняно з Україною; чого цифра не означає. |
| **Ситуації** | `no_data` (якщо `enough_data` хибне) → 2 речення без цифр. Інакше `vs_ukraine`: `above` / `about` / `below` → 3 речення. Невідомі або відсутні значення → `error` (порожній текст, без винятку). |
| **Правила** | Відсоток округлюється «половина вгору». Блок не повторює діапазон і не називає різницю в цифрах. |
| **Код** | `js/interpretation.js` → `buildInterpretation(row)`; тексти — `INTERPRETATION`. |
| **Перевірити** | Три визначення базового рівня (`LEVEL_DEFINITION`, `NEEDS_VERIFICATION`) — звірити з описом рівня 2 у звіті PISA 2025. |

## Частина 4. «Що з цим робити»

| | |
|---|---|
| **Що бачить користувач** | 2–3 картки напрямів: назва, текст, кому адресовано. |
| **Правила вибору** | Шар A (завжди один): хлопці + читання → `read_boys`; дівчата + математика → `math_girls`; інакше `subject_general_<предмет>`. Шар B: нижче становище → `targeted_support`. Шар C: `below` → `system_support`. Якщо менше двох — `universal_school`. Порядок A, B, C. `no_data` → примітка без порад. |
| **Код** | `js/solutions.js` → `buildSolutions(row)`, `missingSources()`; тексти — `DIRECTIONS`. Відкрити сайт з `?debug=1`, щоб побачити позначки `SOURCE_TODO`. |
| **Перевірити / TODO** | Усі 8 напрямів — чернетки (`NEEDS_VERIFICATION`), джерела не заповнені (`missingSources()` → 8 id). Для кожного звірити `claim_to_verify` зі звітом PISA 2025 і заповнити `source_title`, `source_url`, `source_location`. **Увага щодо `math_girls`:** за нашими даними хлопці мають на 8 балів вищий середній бал з математики, але частка дівчат і хлопців, що досягають базового рівня, статистично не відрізняється (−2,3 в.п., SE 1,5). Команді варто вирішити, чи лишати цей напрям. |

## Частина 5. Розрив у роках навчання

| | |
|---|---|
| **Що бачить користувач** | Два порівняння для обраного предмета: дівчата і хлопці з тим самим становищем; нижче і вище становище для обраної статі. |
| **Правила** | Різниця = `mean_score` A − `mean_score` B. Роки = \|різниця\| / 20, округлення до 0,5 «половина вгору», мовні форми від «пів року» до «понад п'ять років». \|різниця\| < 5 → `tiny`; `enough_data` хибне хоча б в одного → `no_data`. Група з вищим балом завжди перша. «у»/«в» перед групою. |
| **Код** | `js/years.js` → `yearsFromPoints`, `formatYears`, `buildGapText`; тексти — `YEARS`. |
| **Перевірити** | `POINTS_PER_YEAR = 20` (`NEEDS_VERIFICATION`). ОЕСР справді називає 20 балів середнім річним приростом, але в тому ж місці радить не переводити різниці в роки навчання (PISA 2022 Results, Vol. I, Box I.5.1, с. 154–156). Речення 2 у шаблоні вже пом'якшує це («допомагає уявити масштаб, а не вимірює його точно»). |

## Що змінено під час збирання (порівняно з промптами)

- **Мова реалізації.** Частини 3–5 у промптах описані як Python-модулі. GitHub Pages виконує лише JavaScript, тому логіку перенесено в JS без змін правил, текстів і округлень. Тести — `node:test` замість `unittest`, з тими самими перевірками.
- **Рядок «усі учні».** У таблиці даних `vs_ukraine` для `gender=all, escs=all` тепер `about` (як у прикладі частини 3), а не `same_group`.
- **Частина 5, речення 2.** `{points}` підставляється разом зі словом «бал/бали/балів» («Різниця в середніх балах: 25 балів»), щоб речення читалося природно.
- **Частина 4, перевірка «без цифр».** Тексти `subject_general_*` містять «15-річні». Це вік, а не статистика, тому тест виключає «15-річн» з перевірки цифр.
- **Частина 2.** Підписи груп у реченні-поверненні узгоджено з частинами 3 і 5 («дівчат з нижчим соціально-економічним становищем родини»). Додано кнопку «Пропустити завдання». Відсотки беруться з таблиці (у прикладі промпту 40,8% — з дещо іншим поділом на групи; у таблиці 40,9%).
