# Калькулятор PISA: Україна

Чи залежить освіта від того, хто ти? Вебсторінка показує, яка частка українських 15-річних досягає базового рівня знань (рівень 2 PISA) залежно від предмета, статі та соціально-економічного становища родини, порівнює її з усіма учнями України та середнім по ОЕСР, пояснює результат і пропонує напрями підтримки.

Дані: OECD PISA 2025, мікродані учнівської анкети, Україна (17 з 27 регіонів), 7 105 учнів у 294 школах.

## Що на сторінці

1. **Перевір себе** — три оприлюднені завдання ОЕСР базового рівня (читання, математика, природничі науки).
2. **Калькулятор** — форма, головна цифра з діапазоном, шкала «твоя група / усі учні України / середнє ОЕСР».
3. **Що це означає** — пояснення простими словами.
4. **Наскільки великий розрив** — різниця між групами в балах і приблизних роках навчання.
5. **Що з цим робити** — 2–3 напрями підтримки залежно від комбінації.
6. **Поділитися** — посилання з обраною комбінацією і картка-картинка для сторіс.

Повна специфікація всіх частин і список того, що треба перевірити: [docs/SPEC.md](docs/SPEC.md).

## Структура

| Файл | Що в ньому |
|---|---|
| `index.html`, `style.css`, `app.js` | Сторінка й основний калькулятор |
| `js/texts.js` | **Усі тексти сайту** — редагувати тут |
| `js/calculator.js` | Логіка калькулятора (частина 1) |
| `js/escs.js`, `data/escs_model.json` | Помічник «Визнач свій рівень» (оцінка достатку з 7 питань) |
| `js/quiz.js` | «Перевір себе» |
| `js/interpretation.js` | «Що це означає» |
| `js/solutions.js` | «Що з цим робити» |
| `js/years.js` | Бали → роки навчання |
| `js/share.js` | «Поділитися»: посилання й картка |
| `js/common.js` | Спільні допоміжні функції |
| `data/pisa_ukraine_calculator.json` / `.csv` | Таблиця результатів для всіх комбінацій |
| `scripts/` | Скрипт, яким пораховано таблицю з мікроданих (самі мікродані в репозиторій не входять) |
| `tests/` | Автоматичні перевірки |
| `docs/` | Специфікація і файли учасниць команди |

## Як запустити локально

```
python3 -m http.server 8000
```
і відкрити http://localhost:8000. Через `file://` дані не завантажаться.

Тести (потрібен Node.js 18+):
```
node --test
```

## Як перерахувати таблицю

Потрібен учнівський файл PISA 2025 (`CY09_MS_STU_PUF.sav`) і Python з `pandas`, `numpy`, `pyreadstat`:
```
cd scripts && python calculator_table.py <шлях до CY09_MS_STU_PUF.sav> ../data
```
